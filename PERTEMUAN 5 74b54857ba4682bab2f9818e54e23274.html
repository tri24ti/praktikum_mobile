📂 Toolbar

Silahkan buat package pertemuan_5 dan buat Activity FifthActivity

Toolbar berfungsi sebagai Action Bar yang menampilkan:

  • Judul aplikasi
  • Tombol navigasi (misalnya: Back, Menu Drawer)
  • Menu Aksi (Search, Settings, Logout, dll.)

Berikut contoh implementasi Toolbar menggunakan XML.

  1. Tambahkan komponen Toolbar di activity_fifth.xml
        <androidx.appcompat.widget.Toolbar
	      android:id="@+id/toolbar"
	      android:layout_width="match_parent"
	      android:layout_height="?attr/actionBarSize"
	      android:background="?attr/colorPrimary"
	      app:titleTextColor="@android:color/white"
	      app:subtitleTextColor="@android:color/white" />
    • Jangan lupa untuk memasang Constraint

  1. Terapkan Toolbar di FifthActivity dan coba jalankan, toolbar akan tampil di bagian atas layar
      
    override fun onCreate(savedInstanceState: Bundle?) {
        ...
				...
				
        setSupportActionBar(binding.toolbar)
        supportActionBar?.apply {
            title = "Activity Fifth"
            subtitle = "Ini adalah subtitle"
            setDisplayHomeAsUpEnabled(true)
            setDisplayShowHomeEnabled(true)
        }
    }
    • Jika tidak ingin ada subtitle, cukup hapus bagian :

      subtitle = "Ini adalah subtitle"

    • Jika tidak ingin ada tombl back, cukup hapus bagian:

      setDisplayHomeAsUpEnabled(true)
      setDisplayShowHomeEnabled(true)

  1. Agar tombol back bisa berfungsi, tambahkan kode berikut dibawah onCreate
        override fun onCreate(savedInstanceState: Bundle?) {{
		    ...
    }
    
    override fun onOptionsItemSelected(item: MenuItem): Boolean {
        return when (item.itemId) {
            android.R.id.home -> {
                onBackPressedDispatcher.onBackPressed()
                true
            }

            else -> super.onOptionsItemSelected(item)
        }
    }

Silahkan pasang Toolbar pada SecondActivity, ThirdActivity, FourthActivity beserta tombol back-nya. Jika sudah ada tombol back pada latihan sebelumnya, silahkan di hapus

📂 Option Menu

Selanjutnya, kita akan menambahkan Option Menu pada toolbar ActivityFitfth

  1. Silahkan buat Android Resourcse Directory di folder /res dan pilih type menu lalu buat file baru dengan nama main_menu.xml

2. Silahkan salin kode berikut ke main_menu.xml sebelum tag </menu> 

<item
    android:id="@+id/action_search"
    android:title="Search"
    android:icon="@android:drawable/ic_menu_search"
    app:showAsAction="ifRoom" />

<item
    android:id="@+id/action_settings"
    android:title="Settings"
    android:icon="@android:drawable/ic_menu_preferences"
    app:showAsAction="never" />
  • ifRoom → Menampilkan ikon jika ada ruang kosong di toolbar.
  • never → Menampilkan item hanya di overflow menu atau saat icon 3 dot di klik.

  1. Agar Option Menu tampil dan berfungsi, kita perlu menambahkan onCreateOptionsMenu() dan melakukan modifikasi pada bagian onOptionsItemSelected() dengan menambahkan action_search dan action_settings :
    		override fun onCreate(savedInstanceState: Bundle?) {
        ...
    }

    override fun onCreateOptionsMenu(menu: Menu): Boolean {
        menuInflater.inflate(R.menu.main_menu, menu)
        return true
    }

    override fun onOptionsItemSelected(item: MenuItem): Boolean {
        return when (item.itemId) {
        
            ... 
            
            R.id.action_search -> {
                Toast.makeText(this, "Search Clicked", Toast.LENGTH_SHORT).show()
                true
            }
            R.id.action_settings -> {
                Toast.makeText(this, "Settings Clicked", Toast.LENGTH_SHORT).show()
                true
            }
            else -> super.onOptionsItemSelected(item)
        }
    }

  1. Silahkan coba di run, maka Option Menu akan tampil di bagian kanan toolbar

    Jika kita mengubah atribut showAsAction milik action_search menjadi never, maka tombol search akan ditampilkan dalam dropdown

📂 Scrollable Content

Android menyediakan dua komponen penting untuk mengatur interaksi antara Toolbar dan konten yang bisa di-scroll, yaitu CoordinatorLayout dan AppBarLayout.

Keduanya berfungsi sebagai “wadah” yang dapat memahami gerakan scroll dari komponen seperti NestedScrollView atau RecyclerView.

Dengan menggabungkan komponen-komponen ini, kita bisa mengatur bagaimana Toolbar bereaksi saat user melakukan scroll halaman — misalnya:

  • Toolbar ikut tersembunyi saat scroll ke bawah,
  • muncul kembali saat scroll ke atas, atau
  • menampilkan efek collapsing toolbar yang terlihat lebih interaktif dan modern.

Sekarang kita akan mencoba menerapkan NestedScrollView untuk menyiapkan konten yang panjang dan bisa di-scroll (scrollable content).

2️⃣ Terapkan CoordinatorLayout dan AppBarLayout

Jika sebelumnya ConstraintLayout memiliki pola berikut

  • Root: ConstraintLayout
  • Toolbar
  • NestedScrollView
  • Scroll → konten akan melebihi Toolbar

Maka kita akan terapkan CoordinatorLayout

  • Root: CoordinatorLayout
  • Toolbar di dalam AppBarLayout
  • Scroll → Toolbar akan tetap diatas dan bisa di sesuaikan untuk show/hide saat scroll

Before

After

KomponenFungsi
CoordinatorLayoutLayout utama yang mengatur interaksi antar komponen (misal toolbar & scroll view).
AppBarLayoutWadah untuk elemen di atas layar (Toolbar, TabLayout, CollapsingToolbarLayout, dll.).
NestedScrollViewKonten yang bisa discroll dan “berkoordinasi” dengan AppBarLayout agar efek scroll bekerja.
app:layout_behavior="@string/appbar_scrolling_view_behavior"Memberitahu sistem bahwa bagian bawah ini mengikuti aturan scroll dari AppBarLayout.

3️⃣ Test scroll dan test behavior lainnya

Saat ini, jika sudah menerapkan CoordinatorLayout dan AppBarLayout maka tampilan scroll sudah sesuai dengan yang diharapkan

Coba tambahkan kode berikut pada Toolbar 

<androidx.appcompat.widget.Toolbar
    ...
    app:layout_scrollFlags="scroll|enterAlways"
/>
  • Scroll ke bawah → Toolbar ikut keatas dan hilang
  • Scroll ke atas → Toolbar akan tampil kembali

Silahkan eksplor lebih jauh untuk jenis-jenis dari layout_scrollFlags

Pada scrollable content, pastikan root nya menggunakan CoordinatorLayout, lalu pada komponen dalamnya baru kita terapkan LinearLayout atau ConstrainLayout

📂 WebView

WebView adalah komponen Android yang memungkinkan aplikasi menampilkan konten web seperti HTML, CSS, dan JavaScript langsung di dalam aplikasi — tanpa perlu membuka browser eksternal.

Dengan WebView, kita bisa membuat halaman web tampil seperti bagian dari aplikasi.

Persiapan awal sebelum menerapkan WebView :

  • Buatlah sebuah Button dengan id btnWebView di dalam LinearLayout pada activity_fifth.xml

    (Perhatikan nested layout-nya)

  • Buatlah Activity baru dengan nama WebViewActivity di pertemuan_5
  • Terapkan onClickListener pada btnWebView untuk berpindah ke WebViewActivity

Jika langkah diatas sudah berhasil, ikut step berikut:

1️⃣ Tambahkan komponen WebView ke activity_web_view.xml
  • Komponen WebView ada di Widgets→WebView
  • Karena hanya akan ada komponen ini, maka constraint bisa di pasang di ke empat sisinya
  • id = webView
  • width height = match_parent

2️⃣ Konfigurasi WebViewActivity dengan menerapkan kode berikut 
    override fun onCreate(savedInstanceState: Bundle?) {
        ...

        binding.webView.webViewClient = WebViewClient()
        binding.webView.settings.javaScriptEnabled = true
        binding.webView.loadUrl("https://merdeka.com")
    }

3️⃣ Tambahkan permission di AndroidManifest.xml untuk mendapat izin akses internet
<uses-permission android:name="android.permission.INTERNET" />

4️⃣ Navigasi ke halaman web sebelumnya

Saat ini, web sudah dapat terbuka di aplikasi. Namun, ketika ingin melakukan navigasi kembali ke halaman web sebelumnya, aplikasi justru menutup WebActivity.

Untuk mengatasi masalah tersebut, kita perlu ambil alih fungsi tombol kembali dengan menerapkan kode berikut di bawah onCreate :

override fun onCreate(savedInstanceState: Bundle?) {
	...
	...
	...
}

override fun onBackPressed() {
    if (binding.webView.canGoBack()) {
        binding.webView.goBack() // Kembali ke halaman web sebelumnya
    } else {
        super.onBackPressed() // Keluar activity sebelumnya
    }
}

Setelah dijalankan, tombol kembali akan mengarahkan kita ke halaman sebelum nya

5️⃣ Menutup WebView dan kembali ke Acivity sebelumnya

Jika kita sudah mengambil alih fungsi tombol kembali, maka kita perlu memasang Toolbar dengan tombol back agar bisa menutup WebActivity.

Sesuaikan activity_webview.xml dengan menerapkan CoordinatorLayout dan Toolbar pada AppBarLayout:

<?xml version="1.0" encoding="utf-8"?>
<androidx.coordinatorlayout.widget.CoordinatorLayout xmlns:android="http://schemas.android.com/apk/res/android"
    ....>

    <com.google.android.material.appbar.AppBarLayout
        android:id="@+id/appBar"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:theme="@style/ThemeOverlay.MaterialComponents.Dark.ActionBar">

        <androidx.appcompat.widget.Toolbar
            android:id="@+id/toolbar"
            android:background="?attr/colorPrimary"
            android:layout_width="match_parent"
            android:layout_height="?attr/actionBarSize"
            app:titleTextColor="@android:color/white"
            app:layout_scrollFlags="scroll|enterAlways"/>
            
    </com.google.android.material.appbar.AppBarLayout>

    <WebView
        ...
        app:layout_behavior="@string/appbar_scrolling_view_behavior" />

</androidx.coordinatorlayout.widget.CoordinatorLayout>

Jangan lupa set layout_behavior pada WebView

Pada WebViewActivity, terapkan :

  • setSupportActionBar()
  • onBackPressed()
  • setOnScrollChangeListener() 
    override fun onCreate(savedInstanceState: Bundle?) {
        ...
	       
	      // Mengaktifkan toolbar
        setSupportActionBar(binding.toolbar)
        supportActionBar?.apply {
            title = "Web Merdeka"
            setDisplayHomeAsUpEnabled(true)
            setDisplayShowHomeEnabled(true)
        }

        binding.webView.webViewClient = WebViewClient()
        binding.webView.settings.javaScriptEnabled = true
        binding.webView.loadUrl("https://merdeka.com")
        
        // Agar Toolbar hide/show saat scroll web
	      binding.webView.setOnScrollChangeListener { _, _, scrollY, _, oldScrollY ->
            if (scrollY > oldScrollY) {
                binding.appBar.setExpanded(false, true) // sembunyikan
            } else if (scrollY < oldScrollY) {
                binding.appBar.setExpanded(true, true) // tampilkan
            }
        }
    }
    
    //Mengaktifkan tombol back pada toolbar
    override fun onBackPressed() {
        if (binding.webView.canGoBack()) {
            binding.webView.goBack() // Kembali ke halaman sebelumnya
        } else {
            super.onBackPressed() // Keluar dari aplikasi
        }
    }

📂 Vector Asset

Vector Asset merupakan gambar berbasis vektor yang digunakan dalam aplikasi android seperti tombol, logo, dan elemen UI lainnya. Berbeda dengan gambar PNG atau JPG gambar vektor akan tetap tajam di semua ukuran layar.

Kita akan coba menambahkan icon untuk tombol kembali di toolbar dengan warna putih. Silahkan ikuti langkah berikut:

  1. Pada folder drawable, klik New → pilih Vector Asset
  1. Akan muncul modal untuk melakukan kostumisasi terhadap asset yang akan ditambahkan. Klik pada icon “Clip Art”
  1. Akan tampil modal untuk mencari icon, silahkan ketik misal “add”, pilih icon-nya lalu klik OK
  1. Silahkan atur warna menjadi putih dan rename nama icon menjadi ic_arrow_back lalu klik Next → Finish.

    Format penulisan: ic_xxx /ic_add /ic_phone /ic_home /ic_dashboard

Kita coba terapkan untuk mengganti icon dari tombol di Toolbar.

Tambahkan kode berikut pada supportActionBar() di FifthActivity 

supportActionBar?.apply {
    ...
    
    setHomeAsUpIndicator(R.drawable.ic_arrow_back)
}

Kita coba terapkan pada tombol Web View yang telah kita buat sebelumnya.

Silahkan tambah icon baru (pada contoh ini menambahkan ic_add berupa icon tanda tambah) lalu terapkan app:icon dan app:iconGravity :

<Button
  android:id="@+id/btnWebView"
  ...
  app:icon="@drawable/ic_add"
  app:iconGravity="textStart" />
  • Jika app:iconGravity menggunakan textEnd maka icon akan berpindah ke bagian kanan text
